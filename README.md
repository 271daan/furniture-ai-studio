# Furniture AI Studio

가구 제품 사진과 정보를 등록해 상세페이지용 6컷 구성 및 이미지 생성 프롬프트를 만드는 한국어 웹 앱입니다. 첫 버전은 **이미지 자체를 생성하지 않습니다**.

## 설치 없이 웹브라우저에서 보기

GitHub Pages용 자동 배포 설정은 [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)에 있습니다. GitHub Pages에는 **데모 모드**가 배포되며, 사진 내용에 대한 실제 AI 분석은 제공되지 않습니다. 데모에서도 제품 등록, 6컷 기획, 프롬프트 편집·복사, 브라우저 내 프로젝트 저장을 사용할 수 있습니다.

프로젝트 파일이 GitHub 저장소의 `main` 브랜치에 반영된 뒤, 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하세요. 이어서 **Actions → Deploy demo to GitHub Pages → Run workflow**를 누르면 됩니다. 배포가 완료되면 같은 Pages 설정 화면의 **Visit site** 버튼으로 접속할 수 있습니다. 컴퓨터에 프로그램을 설치하거나 터미널을 열 필요가 없습니다.

이 클라우드 온보딩 환경은 개발 서버의 3000번 포트를 외부 웹 미리보기로 공개하지 않습니다. 개발 서버가 실행 중이어도 사용자의 Windows 컴퓨터에서 `localhost`로 접속할 수 없습니다.

## 로컬에서 개발할 때만

1. [Node.js](https://nodejs.org/) 20 이상을 설치합니다.
2. 터미널에서 이 저장소 폴더로 이동합니다.
3. 아래 명령을 차례로 실행합니다.

```bash
npm ci
npm run dev
```

4. 브라우저에서 `http://localhost:3000`을 엽니다.
5. 제품명과 사진을 등록하고 **데모 6컷 기획하기**를 누릅니다. 제품 크기, 소재, 색상, 특징도 입력하면 프롬프트에 반영됩니다.

데모 모드에서는 사진을 **분석하지 않습니다**. 입력 정보에 기반한 공간·구도·6컷 예시를 생성하며 화면에 데모 결과라고 표시합니다. 사진 내용을 실제로 분석하려면 아래의 AI API 설정을 적용하세요.

## 실제 AI 분석 사용하기 (선택)

서버의 환경 변수 `OPENAI_API_KEY`에 사용 가능한 OpenAI API 키를 설정하고 서버를 다시 시작합니다. 저장소 루트의 `.env.example`을 `.env`로 복사해 값을 입력해도 됩니다. `.env`는 Git에 포함되지 않습니다. API 키는 브라우저 코드에 포함되지 않고 서버에서만 OpenAI로 전송됩니다.

```bash
cp .env.example .env
# .env 파일의 OPENAI_API_KEY에 본인의 키를 입력한 뒤
npm run dev
```

기본 모델은 `gpt-4o-mini`이며 `OPENAI_MODEL`로 변경할 수 있습니다. 실제 AI 결과는 **실제 AI 분석 결과**로 표시됩니다. API 요청이 실패해도 데모 결과로 자동 대체하지 않고 오류를 표시합니다. 요청은 OpenAI API 사용량에 따라 요금이 발생할 수 있습니다.

## 사용 방법

- 사진: JPG, PNG, WEBP를 최대 6장, 장당 8MB 이하로 등록합니다.
- 분석: 제품 정보와 사진 1장 이상을 입력한 뒤 기획 버튼을 누릅니다.
- 결과: 제품 분석, 공간 3종, 구도 5종, CUT 01~06의 구상과 개별 프롬프트를 확인합니다.
- 프롬프트: 컷을 선택해 직접 수정하고 **복사**를 누릅니다.
- 공통 지침: 왼쪽 **공통 지침** 메뉴에서 편집합니다. 변경 사항을 프롬프트에 반영하려면 기획을 다시 실행합니다.
- 저장: 상단 **프로젝트 저장**을 누릅니다. **저장된 프로젝트** 메뉴에서 다시 열 수 있습니다.

프로젝트는 현재 브라우저의 IndexedDB에 사진과 함께 저장됩니다. 다른 기기나 브라우저와 동기화되지 않으며, 브라우저 데이터를 지우면 삭제됩니다. 저장 공간이 부족하면 오류가 표시됩니다.

## 확인 및 배포용 실행

```bash
npm test
npm run build
npm start
```

`npm start`는 빌드된 `dist`를 3000번 포트에서 제공합니다. `PORT` 환경 변수로 포트를 변경할 수 있습니다. `npm run dev`는 개발 서버를 같은 포트에서 실행합니다.
